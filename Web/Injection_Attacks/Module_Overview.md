# Injection Attacks

Module: [Injection Attacks](https://tryhackme.com/module/injection-attacks)

In this module, we'll guide you through the complex landscape of injection attacks, focusing on vulnerabilities like SQL Injection, SSTI, LDAP Injection, and XXE Injection. We’ll start with Advanced SQL Injection, where you’ll learn how injection-based attacks can be used for relational databases, leading to data pilferage and RCE. We'll then pivot to NoSQL Injection where you’ll learn the impact of injection attacks on non-relational databases like MongoDB.

Free Rooms Included:
1. [Advanced SQL Injection](https://tryhackme.com/room/advancedsqlinjection)
2. [NoSQL Injection](https://tryhackme.com/room/nosqlinjectiontutorial)
